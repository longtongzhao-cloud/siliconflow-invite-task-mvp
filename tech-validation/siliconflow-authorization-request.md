# SiliconFlow 第三方接入授权询问模板

主题：咨询推荐官计划第三方订单履约工具的接口与书面授权

SiliconFlow 团队您好：

我们拟开发一个用于推荐官订单履约的第三方工具。客户在淘宝购买服务后，系统为其创建邀请任务；参与者在 SiliconFlow 官方页面完成注册和实名认证，本站按完成情况进行人工奖励。

为避免使用未公开接口或违反平台规则，请贵方书面确认以下事项：

1. 是否允许第三方网站接收用户主动输入的 SiliconFlow 手机短信验证码，并代表用户调用登录流程？
2. 是否允许第三方服务端加密保存用户登录会话，最长 24 小时，并在用户撤回、订单结束或到期时立即销毁？
3. 是否有正式开放 API、OAuth/OIDC 或合作接口，可读取本人邀请码、邀请记录、注册状态、实名认证状态及“是否有效认证”？请提供接口文档、授权范围、限流、字段定义和数据保留要求。
4. 是否允许上述状态用于外部有偿任务结算？参与者奖励为每次人民币 5 元，不要求开通服务或消费。
5. 是否允许生成并分享官方邀请短链 `https://cloud.siliconflow.cn/i/{code}`，以及从淘宝订单页、微信群等渠道引导用户前往官方域名完成操作？
6. 是否有推荐的合作主体、合同、应用审核、安全评估、隐私告知或数据处理协议要求？个人开发者是否可以申请，还是必须企业主体？

我们承诺：不绕过验证码、滑块、设备风控或实名认证；不采集身份证、人脸材料；验证码不落库、不进日志；会话采用独立密钥加密并设置不超过 24 小时的强制销毁；所有用户操作均明确告知并取得同意。

如不能授权第三方代收验证码或保存会话，也请确认是否可采用“用户手动粘贴邀请码、全程跳转 SiliconFlow 官方页面、邀请人自行查看官方邀请记录、第三方仅做任务和人工结算管理”的模式。

烦请以邮件或正式工单明确回复允许、禁止及需要另行签约的范围。收到书面确认前，我们不会调用登录写接口、发送短信、保存会话或自动抓取邀请记录。
