# MVP 阶段验收报告

最后复验日期：2026-08-18
结论：**MVP 与 WSL 临时公网 mock 范围通过，已可进行手机端受控试用；生产外部接入未通过。**

## 已通过

- 配置、API、部署与状态机测试：73/73；生产环境会拒绝未声明 Host、演示密钥、mock 上游、mock 短信、远程浏览器未实现模式和演示数据。
- API 并发：N=1、N=5、N=10 均未产生第 N+1 个有效名额。
- 客户流程：订单链接 -> mock OTP -> 代理登录 -> 会话密文 -> 8 位邀请码 -> 任务链接。
- 抢单流程：本站手机号登录 -> 支付宝登记 -> 抢单 -> 注册 -> 有效认证 -> 5 元待支付奖励。
- 超时规则：30 分钟释放、15 分钟提醒幂等、24 小时截止、空余容量下补做获奖、不得侵占活跃保护名额。
- 会话安全：OTP 不落库、令牌 AES-256-GCM 加密、最长 24 小时、过期/退款/关闭后删除。
- 淘宝运营：第一阶段采用人工确认付款、人工建单和人工发送客户链接；测试确认人工建单不依赖淘宝事件。开发环境仍保留付款事件幂等和退款关闭探针。
- 浏览器：桌面客户页/任务页/管理台通过；390px 移动端无横向溢出或遮挡；控制台 0 个错误或警告。
- 权限边界：公开任务不返回邀请码；仅抢单本人可获得官方邀请链接并提交加密的 SiliconFlow 用户 ID 声明。
- 测试部署资产：Ubuntu systemd、Nginx HTTP/HTTPS、显式 UFW、生产烟雾测试和 SQLite 一致性备份已在 WSL 验证；真实云资源尚未开通。
- 临时公网：WSL + Cloudflare Quick Tunnel 已通过公网 HTTPS 健康检查和完整 mock 业务自测，最终奖励状态为 `PAID`；每轮使用随机地址、随机凭据和临时数据库并在退出后删除。
- 本站短信代码：阿里云 PNVS 发送/核验、供应商动态验证码、白名单、60 秒冷却、小时/日预算、5 次核验锁定、单次消费和失败关闭已通过假客户端测试，不保存 OTP 或供应商流水明文。
